# 《图解分布式系统原理》EPUB 设计

## 目标

将 <https://www.codedump.info/dist-system-cn/> 公开目录中的第一章至第七章中文内容整理为一本可离线阅读的 EPUB 3 电子书。电子书应保留图解、公式、代码与原文结构，并提供章—节两级跳转目录。

## 内容范围

- 只收录中文目录中的第一章至第七章，按原始顺序排列：概述、系统模型、时间和顺序、复制、共识算法、分区、事务。
- 每章收录对应章节页面的完整正文，不收录网站导航、面包屑、推荐区、广告、社交链接和站点页脚。
- 书名为《图解分布式系统原理》，作者为 Lichuang。
- 增加封面页和版权／来源页，注明原站链接及页面标示的 CC BY-SA 4.0 许可。

## EPUB 结构

- 封面与书籍元数据。
- 版权／来源页。
- 第一章至第七章，每章一个独立 XHTML 文档。
- EPUB 导航目录以七章为一级目录，以正文中的二级标题为二级目录；三级及以下标题保留在正文中，不扩展导航层级。
- 正文样式针对电子墨水与常见 EPUB 阅读器优化，允许阅读器调整字体和字号。

## 图片、公式和链接

- 下载七章正文引用的全部图片并内嵌到 EPUB，使用稳定、唯一的本地文件名。
- 保留图片替代文字；图片宽度自适应页面，不超出阅读区域。
- 保留网页已经渲染的公式表示；若公式依赖外部脚本，则转换为静态、离线可显示的内容。
- 章内锚点改写为 EPUB 内部链接；外部资料链接保留为 HTTPS 链接。
- 任一图片下载失败时停止生成并报告具体 URL，不交付缺图版本。

## 抓取与清理流程

1. 从总目录解析并锁定第一章至第七章 URL。
2. 下载每个章节页面，提取正文容器及标题层级。
3. 收集、下载并去重正文图片，改写图片引用。
4. 清理站点专用属性和不兼容标签，输出严格有效的 XHTML。
5. 生成封面、来源页、导航文档、清单和书脊，打包为 EPUB 3。

## 验收标准

- EPUB 包含且仅包含七章中文正文，章节顺序与网站目录一致。
- 七章标题均出现在一级目录，章内二级标题均出现在二级目录且可跳转。
- 正文引用的每张图片都存在于 EPUB 内，不依赖网络加载。
- 所有 XHTML、OPF 与容器 XML 均通过 XML 解析。
- EPUB ZIP 结构有效，`mimetype` 为首个未压缩条目。
- 自动逐章对比网页与电子书的标题、二级标题和正文末段，防止内容截断。
