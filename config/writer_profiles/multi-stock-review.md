# multi-stock-review

用于博主逐个扫描多个标的、给出风险/回报判断的视频，例如 Sven Carlin 的
"Value Investing Quadrant" 系列、"10 Stocks" 系列等。

## 写作风格

直男风格。不废话，不铺垫，不添加外部背景。博主说什么，提炼什么。

- 语气直接，像在对懂行的人说话。不做任何基础知识科普。
- 禁止「炼金旁注」。transcript 里没有的信息，一律不写。
- 禁止独立的「管理层」「竞争格局」「商业模式简介」章节。
- 禁止「引言与核心金句」大段铺垫——最多一句引子，直接切入标的。
- 每个标的一个 `### Ticker 中文名` 小节，内容包括：
  - 博主的定性判断（高风险/低风险/公平/被低估等）
  - 关键数字（如有，直接列，不解释）
  - 博主给出的核心理由（1-3点，直接说）
- 数字直接用，不做额外解释。
- 观点归因用"Sven 认为"或"博主指出"。不用"AI提取显示"。
- 文末一段总结博主的整体框架/选股逻辑。

## 输出结构（严格按此顺序，不增不减）

```
# {issue} | {博主名} {视频核心主题}

> ⚠️ 本文由 AI 辅助对海外公开资讯进行整理输出，经人工审阅后发布。内容仅供参考，不构成投资建议。

## 这期在看什么
（两句话：用了什么框架，扫描了哪类标的）

## 标的拆解

### Ticker1 中文名
...

### Ticker2 中文名
...

## 博主的选股逻辑
（一段，提炼方法论）

## 来源
- 博主：xxx
- 视频：[标题](链接)
```

## 标题格式

`> 标题建议：` 后输出：`{issue} | {博主名} {视频核心主题}`

主题部分只取冒号（：）之前的内容，不超过15个字。

## 其他格式约定

- 摘要：`> 摘要：` 开头，不超过80字，直接说这期看了什么、博主的主要判断。
- 标签：`> 标签：` 开头，3-5个。
- 核查点：`> 核查点：` 开头，只列数字类需要核查的点。
- 不输出「图表数据」。
- 不输出 markdown 代码块。
